# Image Converter Web Application

## Overview
A Flask-based web application that converts images into different formats through a simple web interface.

## Features
- Upload images
- Convert to multiple formats
- Fast processing
- Simple UI

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Pillow
- Git
- GitHub

## Installation

git clone <repository>

pip install -r requirements.txt

python app.py
